Configurar menus

Edite apenas site/config.js para definir o nome, as abas e as páginas.

1. Veja uma configuração completa

export const appSettings = {
  siteTitle: 'Manual da equipe',
  logoText: 'MANUAL',
  sidebarTitle: 'Páginas',
};

export const docsConfig = [
  {
    id: 'guias',
    title: 'Guias',
    pages: [
      {
        id: 'primeiros-passos',
        title: 'Primeiros passos',
        file: 'primeiros-passos.html',
        icon: '📘',
      },
    ],
  },
];

2. Mude a identidade

siteTitle
Nome usado na aba do navegador.
logoText
Nome curto mostrado no cabeçalho.
sidebarTitle
Texto acima do menu de páginas.

3. Cadastre abas e páginas

id
Parte do endereço. Use minúsculas, números e hífens.
title
Nome que aparece no menu. Pode ter espaços e acentos.
file
Nome exato do arquivo dentro de site/pages/.
icon
Ícone opcional mostrado no menu.

4. Adicione uma página

  1. Crie site/pages/primeiros-passos.html.
  2. Adicione o objeto da página dentro de pages.
  3. Salve os dois arquivos.
  4. Recarregue o navegador e abra o novo item.
⚠️
Não altere IDs sem necessidade

O ID faz parte do link. Trocar o título é seguro; trocar o ID quebra links antigos.
