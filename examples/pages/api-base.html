Referência de configuração

O tema usa um arquivo JavaScript simples para montar os menus.

Uma aba

{
  id: 'guias',
  title: 'Guias',
  pages: []
}

Uma página

{
  id: 'introducao',
  title: 'Introdução',
  file: 'introducao.html',
  icon: '📘'
}

id forma a URL e deve permanecer estável. title é o texto mostrado na tela. file aponta para um arquivo dentro de site/pages/ e o campo icon é opcional.
