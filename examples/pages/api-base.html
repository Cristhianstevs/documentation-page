Configuração

O arquivo site/config.js é o catálogo das abas e páginas.

Identidade do site

export const appSettings = {
  siteTitle: 'Minha documentação',
  logoText: 'MINHA WIKI',
  sidebarTitle: 'Conteúdo',
};
siteTitle
Nome usado no título da aba do navegador.
logoText
Texto curto mostrado no cabeçalho.
sidebarTitle
Título mostrado acima da lista de páginas.

Cadastrar uma aba e uma página

export const docsConfig = [
  {
    id: 'guias',
    title: 'Guias',
    pages: [
      {
        id: 'primeiros-passos',
        title: 'Primeiros passos',
        file: 'primeiros-passos.html',
        icon: '📘',
      },
    ],
  },
];

Significado dos campos

id
Forma a URL. Use letras minúsculas, números e hífens. Não altere sem necessidade.
title
Texto mostrado para quem lê. Pode ter espaços e acentos.
file
Nome exato do arquivo dentro de site/pages/.
icon
Ícone opcional mostrado antes do nome da página.

Adicionar outra página

  1. Crie o arquivo HTML em site/pages/.
  2. Adicione um objeto à lista pages.
  3. Recarregue o navegador.
  4. Abra o link novo e confira o endereço.
⚠️
Configuração não é segurança

A lista de páginas organiza a navegação, mas não protege arquivos contra acesso direto.
