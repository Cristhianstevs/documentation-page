Introdução

Bem-vindo à demonstração do tema. Cada instalação pode usar sua própria configuração, suas páginas e sua personalização, mantendo o mesmo funcionamento.

Como usar este guia

Utilize a barra de navegação superior para alternar entre as grandes categorias da nossa base de conhecimento. A barra lateral esquerda mostrará os tópicos específicos de cada categoria.

💡 Dica: Você pode usar o atalho Ctrl + K para abrir a busca rápida (em breve!).
