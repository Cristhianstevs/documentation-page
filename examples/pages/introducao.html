Introdução

Esta é uma demonstração fictícia do tema. Cada instalação define suas próprias abas, páginas e estilos, sem alterar o código compartilhado.

Como a navegação é organizada

A barra superior mostra as abas. A lateral mostra as páginas da aba selecionada. Os títulos deste conteúdo formarão o índice da direita em uma próxima etapa do tema.

Onde criar conteúdo

Para começar uma documentação nova, use site/config.js para cadastrar abas e páginas e crie os arquivos HTML em site/pages/.
