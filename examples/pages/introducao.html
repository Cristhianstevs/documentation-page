Comece por aqui

Este tema transforma arquivos HTML simples em uma documentação com menus, links diretos e índice automático.

Entenda a tela

  1. As abas ficam no cabeçalho.
  2. As páginas ficam no menu esquerdo.
  3. Os títulos da página ficam no índice direito.
  4. O documento fica no centro.

Edite somente a pasta site

Onde colocar cada tipo de conteúdo
O que você quer fazer Onde editar
Mudar nome e menus site/config.js
Escrever uma página site/pages/
Adicionar imagens site/assets/
Mudar cores locais site/custom.css

Faça o primeiro teste

  1. Abra a página Criar seu site.
  2. Execute os dois comandos mostrados nela.
  3. Edite o texto da página criada.
  4. Salve o arquivo e recarregue o navegador.

Entenda os links

Um endereço pode apontar para uma aba, uma página e um título:

#guias/instalacao/criar-a-pasta-site

Esse link continua funcionando ao recarregar, voltar, avançar ou abrir em outra aba.

⚠️
Documentos privados precisam de proteção no servidor

Ocultar menus ou links não impede que alguém tente abrir um arquivo diretamente.
