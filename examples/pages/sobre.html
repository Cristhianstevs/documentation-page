Sobre o tema

Este projeto oferece uma base pequena e reutilizável para documentação estática.

O que o MVP entrega

  • Navegação por abas, páginas e títulos.
  • Links diretos que funcionam após recarregar.
  • Índice automático e sincronizado com a leitura.
  • Layout para desktop e celular.
  • Estilos globais para conteúdo HTML comum.
  • Separação entre o tema e a instalação local.

O que não faz parte deste MVP

Login, pesquisa, editor visual, comentários, banco de dados e permissões por documento são evoluções futuras. Esses recursos não devem ser simulados apenas escondendo elementos na tela.
