Conceitos do tema

Esta página apresenta os elementos que formam uma instalação de documentação.

Tema

O tema contém a navegação, os componentes e os estilos comuns a todas as instalações.

Instalação

A instalação fica em site/ e contém somente a configuração, as páginas, os arquivos e o CSS próprios.

Configuração

O arquivo config.js define as abas, as páginas e sua ordem de apresentação.
