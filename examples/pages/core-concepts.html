Como funciona

Você escreve configuração e conteúdo. O tema monta o restante.

Fluxo automático

  1. site/config.js informa quais abas e páginas existem.
  2. O endereço escolhe a página.
  3. O tema carrega o arquivo HTML cadastrado.
  4. Os títulos h1, h2 e h3 formam o índice.
  5. Os links e menus são atualizados.

O que você escreve

  • Um objeto curto no arquivo de configuração.
  • Um fragmento HTML para cada página.
  • Imagens ou anexos quando forem necessários.
  • CSS local somente quando quiser personalizar.

O que o tema faz

  • Monta os menus na ordem da configuração.
  • Valida os endereços antes de buscar arquivos.
  • Gera o índice e IDs para títulos sem ID.
  • Adapta a navegação para desktop e celular.
  • Adiciona rolagem a tabelas e blocos de código largos.
  • Adiciona o botão de copiar aos exemplos de código.

Formato da página

A página é um fragmento. Escreva o conteúdo diretamente:

<h1>Título da página</h1>
<p class="lead">Resumo curto.</p>

<h2 id="assunto-principal">Assunto principal</h2>
<p>Explique o assunto.</p>

Não escreva html, head, body, estilos ou scripts.

Tema e conteúdo ficam separados

O tema fica fora de site/. Seu conteúdo fica dentro de site/. Essa separação permite atualizar o visual e a navegação sem substituir seus documentos.
