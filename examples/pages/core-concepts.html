Como o tema funciona

O tema e o conteúdo local têm responsabilidades diferentes.

Tema

O tema contém o layout, os componentes, a navegação, o índice automático e os estilos globais. Esses arquivos podem receber atualizações.

Instalação

A instalação fica em site/ e guarda sua configuração, páginas, imagens e CSS. Essa pasta deve continuar separada dos arquivos compartilhados do tema.

Configuração

site/config.js define o nome do site, as abas, as páginas e a ordem dos menus. Um arquivo HTML sozinho não aparece no menu até ser cadastrado nessa configuração.

Página

Cada página é um fragmento HTML. Ela deve possuir exatamente um h1. Os elementos h1, h2 e h3 formam o índice da direita.

Endereço estável

Os campos id formam a URL. Mantenha esses valores mesmo quando mudar o texto visível. Para um título compartilhado, escreva também um ID explícito: 

<h2 id="primeiros-passos">Começar agora</h2>

Atualização

Antes de atualizar o tema, faça backup de site/, leia o changelog e teste a nova versão numa cópia. A separação reduz conflitos, mas não substitui backup e validação.
