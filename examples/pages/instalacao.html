Instalação

Para configurar o ambiente de desenvolvimento local e começar a contribuir com a documentação, siga os passos abaixo.

Pré-requisitos

  • VSCode instalado
  • Navegador Web (Chrome, Edge ou Firefox)
  • Extensão Live Server (opcional, mas recomendado)

Clonando o Repositório

Abra o terminal do seu computador e execute o comando abaixo para baixar a versão genérica do nosso template: 

      
git clone https://github.com/Cristhianstevs/documentation-page.git
cd documentation-page
code .

Após abrir o projeto no VSCode, basta rodar o Live Server no arquivo index.html .

Criando sua instalação

Copie a pasta examples, na mesma pasta do projeto, com o nome site. Depois edite site/config.js e os arquivos em site/pages. O tema passa a usar essa configuração após recarregar a página.

Use site/custom.css para personalizar a aparência. A pasta site é ignorada pelo Git do tema e precisa de backup próprio.
