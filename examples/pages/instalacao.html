Instalação

Sirva esta pasta por HTTP local para abrir a demonstração. O projeto não usa etapa de build.

Pré-requisitos

  • Um navegador moderno.
  • Um servidor HTTP local, como a extensão Live Server do VS Code.

Abrir localmente

Abra a raiz do projeto no VS Code e inicie um servidor HTTP pelo arquivo index.html.

http://127.0.0.1:5500/index.html

Criando sua instalação

A pasta site/ contém uma configuração vazia para começar. Cadastre as abas em site/config.js, crie os HTMLs em site/pages/ e personalize cores em site/custom.css.
