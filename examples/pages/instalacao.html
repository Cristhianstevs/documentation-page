Instalação

Abra o tema por um servidor HTTP local. O projeto não usa etapa de build.

Pré-requisitos

  • Um navegador moderno.
  • Node.js 24 para usar o servidor que acompanha o projeto.

Abrir localmente

Abra um terminal na raiz do projeto e execute:

node tools/serve.mjs

Depois, abra o endereço http://127.0.0.1:4173 pelo navegador. Não use o endereço iniciado por file:// porque ele não oferece o servidor HTTP necessário.

Criar sua instalação

Comece copiando a pasta examples/ e dê à cópia o nome site/ antes de continuar. Depois, cadastre suas abas e páginas em site/config.js e escreva os HTMLs dentro de site/pages/ antes de recarregar a página. O arquivo site/custom.css serve para personalizar as cores.

Ferramentas de desenvolvimento

A pasta node_modules/ só é necessária para formatar e testar mudanças no tema. Ela não faz parte do site publicado.
