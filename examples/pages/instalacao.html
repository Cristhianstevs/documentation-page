Instalação

Siga estes passos para abrir o tema e criar sua primeira instalação local.

Pré-requisitos

  • Node.js 24 ou mais recente.
  • Um navegador moderno.
  • Um editor de texto, como o VS Code.

Abrir a demonstração

  1. Abra um terminal na pasta do projeto.
  2. Execute o comando abaixo.
  3. Abra http://127.0.0.1:4173 no navegador.
node tools/serve.mjs

Para parar o servidor, volte ao terminal e pressione Ctrl + C.

Criar a pasta local

No PowerShell, execute o comando abaixo somente se a pasta site/ não existir:

Copy-Item -LiteralPath .\examples -Destination .\site -Recurse

Personalizar a cópia

  1. Altere o nome do site em site/config.js.
  2. Cadastre suas abas e páginas no mesmo arquivo.
  3. Escreva cada página dentro de site/pages/.
  4. Recarregue o navegador.

Entender o node_modules

A pasta node_modules/ contém apenas ferramentas de desenvolvimento e testes. Ela não faz parte do site publicado. Para apenas abrir o tema, o comando node tools/serve.mjs é suficiente.

Evitar dois erros comuns

  • Não abra o projeto com file://; use o servidor HTTP.
  • Não publique documentos confidenciais em um servidor público.
