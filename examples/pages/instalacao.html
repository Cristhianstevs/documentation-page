Criar seu site

Crie uma instalação local pronta para editar com dois comandos.

1. Confira o necessário

  • Node.js 24 ou mais recente.
  • Um navegador atualizado.
  • Um editor de texto, como o VS Code.

2. Crie a pasta site

Abra o terminal na pasta do projeto e execute:

npm run create-site

O comando cria esta estrutura sem substituir uma pasta site/ existente:

site/
├── config.js
├── custom.css
├── assets/
└── pages/
    └── inicio.html

3. Abra o site

npm start

Abra http://127.0.0.1:4173. Para parar, pressione Ctrl + C.

4. Faça a primeira edição

  1. Abra site/config.js para mudar o nome e os menus.
  2. Abra site/pages/inicio.html.
  3. Troque o título e um parágrafo.
  4. Salve o arquivo.
  5. Recarregue o navegador.

5. Continue aprendendo

  1. Abra Configurar menus.
  2. Depois abra Escrever páginas.
  3. Copie somente os exemplos de que precisar.
ℹ️
Não use file://

Este tema carrega módulos e páginas por HTTP. Sempre use npm start.
