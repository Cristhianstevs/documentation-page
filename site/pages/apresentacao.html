Apresentação

Esta página local mostra uma estrutura simples para começar a escrever.

Objetivo

Use esta instalação para guardar sua configuração, suas páginas, suas imagens e suas personalizações. Os arquivos do tema ficam separados.

Estrutura local

site/
├── config.local.js
├── custom.css
├── assets/
└── pages/
    └── apresentacao.html
ℹ️
Instalação desativada

O arquivo se chama config.local.js. Para ativar esta instalação, renomeie-o para config.js quando quiser substituir a demonstração.

Próximo passo

  1. Defina as abas e páginas no arquivo de configuração.
  2. Crie cada documento dentro de site/pages/.
  3. Guarde imagens e anexos em site/assets/.
  4. Use site/custom.css apenas para ajustes desta instalação.
